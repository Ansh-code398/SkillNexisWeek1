# Week 1: Frontend Fundamentals & React Architecture

This repository contains the assignments and mini project for Week 1 of the SkillNexis curriculum.

## Directory Structure
- [Assignment1/](file:///Volumes/Development/Internships/SkillNexis/Week1/Assignment1)
  - **Personal Portfolio Website**
  - Fully responsive personal portfolio built with semantic HTML5 and modern CSS3.
  - Sections: About, Education, Projects, and Contact.
- [Assignment2/](file:///Volumes/Development/Internships/SkillNexis/Week1/Assignment2)
  - **React Components Practice**
  - 5 reusable React components: `Header`, `Footer`, `Card`, `Button`, and `Form`.
  - Dynamic rendering using props and local state with an interactive testbed.
- [MiniProject/](file:///Volumes/Development/Internships/SkillNexis/Week1/MiniProject)
  - **React Blog UI**
  - Engineering blog layout displaying post cards loaded from a structured JSON dataset (`posts.json`).
  - Search across titles, tags, and authors, category filter chips, tag filters, sorting, bookmarks, and full article reading modal.

## Quick Start

### Assignment 1
Open `Assignment1/index.html` directly in your browser or run:
```bash
npx serve Assignment1
```

### Assignment 2
```bash
cd Assignment2
bun install && bun run dev
```

### Mini Project
```bash
cd MiniProject
bun install && bun run dev
```
