# Assignment 1: Personal Portfolio Website

A responsive, high-performance personal portfolio website built with semantic HTML5 and modern CSS3.

  - **Projects**: Production-grade systems (Circles, LabelJaano, IPU Ki Paathshala, Shhh-Chat, Loltube, BharatSaarthi) with tech stack tags and links.
  - **Contact**: Interactive, accessible contact form and verified direct channels (Email, GitHub, Portfolio).

## Features
- **Semantic HTML5 Architecture**: Accessible landmarks (`header`, `main`, `section`, `article`, `nav`, `footer`).
- **Modern CSS Layouts**: CSS Grid, Flexbox, logical properties (`inline-size`, `block-size`, `margin-block`), and CSS custom properties.
- **Responsive & Mobile-Ready**: Fluid clamp typography and responsive breakpoints for desktop, tablet, and mobile devices.
- **Accessible Forms**: Standard Gestalt proximity spacing, `:user-invalid` pseudo-class styling, `aria-describedby` hints, and `font-size: max(1rem, 1em)` input zoom prevention.
- **Interactive Enhancements**: Lightweight vanilla JavaScript for active navigation tracking, mobile hamburger drawer, and contact form submission feedback.

## Running Locally
Open `index.html` in any modern web browser or serve via any static HTTP server (e.g. `npx serve .` or `python3 -m http.server`).
